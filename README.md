# 📈 Agregador de Investimentos

API REST desenvolvida em **Java** com **Spring Boot** e **Maven**, focada em arquitetura limpa, boas práticas de programação e testes unitários.

## 🛠️ Tecnologias

- **Linguagem:** Java
- **Framework:** Spring Boot
- **Build:** Maven (`mvnw`)

## 🚀 Como executar

```bash
# Clonar o repositório
git clone https://github.com/PedroPog/agregador_de_investimentos.git
cd agregador_de_investimentos

# Executar os testes
./mvnw test

# Iniciar a aplicação
./mvnw spring-boot:run
```
